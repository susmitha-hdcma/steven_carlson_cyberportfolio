CADMedic.AI

Founder · Architect · Engineer
Case study → cadmedic.ai ↗

An AI-integrated operations platform for private EMS agencies — one transport record from request to revenue.

I worked as a specialty-care transport paramedic, so I built the system my industry actually needs: a unified platform replacing the disconnected tools EMS agencies juggle today. CAD dispatch with live unit tracking, ePCR field charting, billing and revenue cycle, fleet management, controlled-substance custody, workforce scheduling, a secure facility request portal, and an offline-capable iOS field app — one data model, end to end.

Because it handles patient data, HIPAA alignment is designed in from the first line: PHI protection, role-based access, audit trails, and chain-of-custody for controlled medications.

WaymarkHQ

Founder · Architect · Engineer
Case study → waymarkhq.com ↗

A governance control plane for AI coding agents — move at AI speed, keep production under control.

AI agents are getting faster; production is not getting safer. Waymark puts a trusted boundary between agent intent and privileged action: a native macOS Studio that orchestrates agent runs in isolated workspaces with approvals, checks, and releases in one view — and a Broker that keeps credentials and privileged commands outside agent reach, enforces policy before execution, and preserves a durable evidence trail for every change.

This is classic security doctrine — least privilege, separation of duties, auditability — applied to the newest attack surface in software: agentic development.

Capability evidence

AI Security Credential isolation, policy-before-execution enforcement, and evidence trails for autonomous coding agents — CISSP domains applied to AI risk.
CI/CD Governance Release checks, approval gates, isolated git worktrees per agent run, and built-in recovery (RepoSeatbelt) across multi-repo delivery.
Development Native macOS application, git infrastructure tooling, and MCP (Model Context Protocol) integration.
Product Strategy Identified the governance gap in the fastest-moving segment of software and positioned a product architecture (Studio, Broker, Forge) to close it.
AI Agent Governance Least Privilege Policy Enforcement Audit Evidence macOS Git Infrastructure MCP DevSecOps
